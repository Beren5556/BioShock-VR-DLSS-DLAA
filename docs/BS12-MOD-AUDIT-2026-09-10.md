## Shared mode-change failure

BS2 18:45 and BS1 18:49 logs start DLAA successfully at 2950×2950. After NORMAL, DLSS is requested at 1/2 preference. Policy rounded odd 1475 down to even 1474. NGX advertises Performance minimum 1475 and rejects it:

```text
optimal 1475x1475, render range 1475x1475 .. 2950x2950
Performance selected by optimum rejects render 1474x1474
```

Code then restores the previous mode. These runs show this rejection, not the old persistent second-eye disable; BS2 ends through orderly shutdown.

Changes:

- Shared core/both launchers choose 1476, retaining even dimensions/exact aspect ratio. Preferences ≥50% never round below the included runtime's 50% boundary. Other rounding/preferences remain.
- Host remains authoritative: no artificial range expansion or preset change to hide incompatibility. This does not promise every custom percentage with every runtime.
- Other NVIDIA rejections retain a range-specific message. Overlay state now owns its text; previously it pointed at a buffer release() overwrote with “disabled”, hiding the cause. Rollback retains prior settings.

This is **not a controlled scene comparison**, and does not quantify expected matching performance or identify each invalidating write. It does rule out simply “the flag was off”. Capture policy retains BS1's criterion: skip only an identical source without potential depth writes.
