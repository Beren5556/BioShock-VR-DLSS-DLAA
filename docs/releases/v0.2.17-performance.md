# Performance · BioShock 1–2 VR DLSS/DLAA

The 0.2.17 English edition retains the rendering behavior of the Spanish
0.2.16 base accepted by the user in both games. The core and launchers are
rebuilt only for translated text and release metadata.

## Preserved optimizations

- Overlap DLSS work between the two eyes.
- Reuse captured depth only when no intervening writes invalidate it.
- Overlap independent frame-tail work with DLSS processing.
- Submit to the headset before finishing desktop-mirror work.

Each game keeps its own camera/depth capture, projection, weapon handling
and exit policy. Shared optimizations do not mean equal rendering passes
or equal engine cost.

## Expectations

DLAA processes the full resolution and may cost more than NORMAL. DLSS
reduces internal resolution but adds processing, copies and synchronization.
The result depends on the bottleneck and scene; higher FPS is not guaranteed
in every situation.

Earlier BioShock 1 tests found a significant cost from reflections and a
smaller penalty from water ripples. Defaults disable both; upgrades respect
existing preferences. For BioShock 2, save graphics changes in the launcher
and restart the game.

The audit observed fewer depth-reuse opportunities in BioShock 2 than in
BioShock 1, in different scenes. This was not a controlled comparison or proof
of a water bug. The core retains passive BS2 diagnostic counters; depth
guards and eye separation are not weakened to improve those counters.

The DLSS range correction prevents rejection when switching modes; it is
not an FPS optimization. Acceptance on one PC does not replace testing on
other headsets and computers.
