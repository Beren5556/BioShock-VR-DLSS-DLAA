# BioShock VR DLSS/DLAA 0.2.11 — historical notes

Fixes persistent stereo loss and installer versioning. At preparation, final headset confirmation remained pending.

## Changes

- Bounded DLSS/DLAA bridge waits and failure shutdown are no longer mistaken for engine deadlock requiring second-eye disable. Wait bounds/eye checks retained.
- After automatic stereo disable, recovery occurs at a new frame after half a second of confirmed progress. No reenable after user OFF, during loading, with engine error or multithreaded rendering.
- Host failures still use fallback; not every NVIDIA failure is claimed eliminated. Fix prevents persistent flat imagery from unrecovered second-eye loss.
- New MSI version/product identity upgrades 0.2.10 without prior uninstall. Same MSI supports repair. Delivered versions cannot be regenerated under the same identity.
- Simplified text, default-enabled desktop-shortcut checkbox and final manual-launch instructions retained. No automatic launcher opening.

## Retained behavior

Four performance optimizations, NORMAL/DLSS/DLAA, compact launcher, graphics options/headset menu. Resolution: 100-pixel steps. Headset DLSS quality: 5-percentage-point steps; launcher: 100-internal-pixel steps. Saved values unchanged.

**F1 opens/cycles headset pages.** F2 decrease/previous, F3 increase/next. Only Graphics options uses F2/F3 row selection and F4 value toggle; F4 does nothing elsewhere.

## Install

Close game/launcher and install MSI 0.2.11 into the same folder. Do not delete old mod/INIs. Preferences retained. Optional shortcut: **BioShock VR DLSS-DLAA 0.2.11**.

Reopen same MSI and choose **Repair** to reinstall. Fresh game installs must run once first to create the INI. Defaults: reflections/ripples off, other tested options on, fluids High.

NVIDIA 310.7.0.0 included; alternative x64 DLL allowed with nonblocking warning at user's risk. Repair restores included DLL. No DLSS 5 Neural Rendering.
