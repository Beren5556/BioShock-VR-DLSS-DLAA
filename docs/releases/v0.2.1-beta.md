# BioShock VR DLSS/DLAA Beta 0.2.1 — historical release

First public fork beta, based on the validated functional core of 0.2. Historical asset:
**Instalador BioShock VR DLSS-DLAA Beta 0.2.1.exe**, containing VR mod, per-eye bridge, runtime, licenses and launcher.
SHA-256: `7B79BF92BDFEFFF1F857E783F8D9EDA11A62010BBA9C915C1F167BFBA07A6A69`.

## Changes

- Public presentation with stronger credits, licenses/provenance.
- Visible original-author acknowledgement on GitHub, installer, launcher and installed documentation.
- Same 0.2.0 functional core: NORMAL/DLAA/DLSS 4.5; no FXAA/spatial-upscaling/full-INI editor.
- One Build\Final selection, no previous mod needed.
- Previous-state restoration and SHA-256 validation of every resource.

## Requirements and limits

Compatible Windows BioShock Remastered/BioShock VR v0.8.2, PCVR environment and NVIDIA RTX for DLAA/DLSS. Supported BioshockHD.exe SHA-256:
`AEC21A0072CFDB15E4B525E2320C87256F14F16894F714272069270AD099A05B`.
NORMAL does not use DLSS.

Experimental unsigned executable. No DLSS 5 Neural Rendering, Frame Generation or Ray Reconstruction. Close game before install/restore. Keep installer: restoration uses the first installation's saved state. No game files/assets included.
