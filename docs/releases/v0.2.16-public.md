# BioShock 1–2 VR DLSS/DLAA 0.2.16 — Spanish release

One MSI with complete mods for **BioShock Remastered** and **BioShock 2 Remastered**. Choose one game on the first page; each run installs, upgrades or repairs only that mod. Run once per game to install both.

These are English-translated release notes; the Spanish release assets remain unchanged.

## Download and install

Download **[BioShock-1-2-VR-DLSS-DLAA-0.2.16.msi](https://github.com/Beren5556/BioShock-VR-DLSS-DLAA/releases/download/v0.2.16/BioShock-1-2-VR-DLSS-DLAA-0.2.16.msi)**.
No original mod preinstallation needed. No games/assets included; requires a legitimate compatible Steam copy.

1. Launch the game once through Steam to create configuration, then close it.
2. With game/launcher closed, open MSI and choose the game.
3. Confirm Build\Final containing BioshockHD.exe or Bioshock2HD.exe.
4. Install, then open its launcher from that folder or optional desktop shortcut.
5. Choose NORMAL/DLAA/DLSS and **Save and launch**.

Existing users: do not delete mod files/backups. Installer manages upgrade and preserves preferences. Reopen the same MSI for repair.

## Changes

- Shared Image interface/temporal optimizations, separate engine adapters, settings and backups.
- Fixed 50% DLSS rounding below NVIDIA's minimum. Rejection preserves prior setting/reason.
- Fixed BS2 capability profile for DLSS/DLAA.
- Native individual-selector MSI with upgrade, repair, original recovery and BS2 beta migration.
- No automatic game launch during installation. Launcher closes after confirmed startup or stays open with a warning.

Installer version **0.2.16**; core/launcher internals **0.2.13**, exactly user-tested/accepted in both games, not rebuilt for publication.

## Controls, compatibility and limits

**F1** opens/cycles headset pages; **F2/F3** decrease/increase. On BS1's graphics page only, F2/F3 select rows and **F4** toggles values. BS2 effects save in launcher/restart. Change resolution in launcher/mod, not internal game options.

DLSS/DLAA require NVIDIA RTX/compatible driver. Includes **NVIDIA DLSS 310.7.0.0 x64**; alternatives allowed with warning/no guarantee. NORMAL does not use DLSS. **No DLSS 5 Neural Rendering or Frame Generation.**

User accepted both mods. Additionally verified: 46 MSI files, both launchers, 12 core suites and 130 checks in 22 isolated MSI operations including upgrade/rollback. Isolated identities avoid everyday game installations.

Another-PC validation remains pending; no equal-FPS guarantee between games/computers/scenes. BS1 retains inherited host-fault protection during window destruction; that exit is not claimed native/fault-free.

MSI **not digitally signed**. Verify SHA-256; do not disable SmartScreen/antivirus.
