# BioShock VR DLSS/DLAA Beta 0.2.3 — historical prerelease

Installer/startup/restoration reliability update based on 0.2.2 user tests.
Historical asset: **Instalador-BioShock-VR-DLSS-DLAA-Beta-0.2.3.exe**.
SHA-256: `2722C00F1C354781428213CA7CE5C28FDE56D86EA13CB8A8FAF59D36FE616EE0`.

## Changes

- Successful installation is not reported failed merely because Windows blocks subsequent launcher opening; shortcut/manual path provided.
- **Save and launch** waits for the actual BioShock process before closing.
- Steam timeout after 30 seconds offers direct launch; failure leaves launcher open with error.
- Restoration removes empty package directories and explains retained preferences/recovery backup.
- Actual 0.2.2 migration/directory cleanup included in automation.

## Installation

Run unmodded BioShock Remastered once to main menu and close it. Open 0.2.3 installer, select compatible Build\Final, install, choose NORMAL/DLAA/DLSS and **Save and launch**.

## NVIDIA and limits

Includes tested/recommended nvngx_dlss.dll 310.7.0.0. Manual alternative x64 DLL allowed with warning, no functionality/stability/image-quality guarantee, at user's risk.

Experimental unsigned prerelease for testers. SmartScreen/antivirus may issue heuristic alerts: do not disable protection or add exclusions; verify SHA-256 and report the exact detection if blocked. No DLSS 5 Neural Rendering, Frame Generation or Ray Reconstruction. Close game before install/restore. Full second-PC basic workflow remained pending before stable promotion.
