# BioShock VR DLSS/DLAA Beta 0.2.2 — historical candidate

First-run/advanced-runtime compatibility update based on initial external feedback.
Historical asset: **Instalador BioShock VR DLSS-DLAA Beta 0.2.2.exe**.
SHA-256: `1C35B82A417C1A8AE5F9A71C688E27221E7C6E8E9859513C6F806E58C96977A4`.

## Changes

- Requires prior game launch and existing Bioshock.ini before mod installation.
- Prominent warning/status refresh when returning to installer.
- Launcher closes when Steam/direct executable accepts startup.
- NVIDIA DLSS 310.7.0.0 remains tested/recommended.
- Other x64 nvngx_dlss.dll allowed with nonblocking warning; functionality/stability/quality not guaranteed, at user's risk.
- Reinstall restores included 310.7.0.0.

## Installation

Run unmodded BioShock Remastered once to main menu and close it. Open 0.2.2 installer, choose compatible Build\Final, install, select NORMAL/DLAA/DLSS and **Save and launch**.

Experimental unsigned beta; no DLSS 5 Neural Rendering, Frame Generation or Ray Reconstruction. Host still applies tested K/M/L mapping; another DLL may interpret/support profiles differently. Close game before install/restore.
