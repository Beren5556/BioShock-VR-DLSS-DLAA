Revisión de primera ejecución y compatibilidad avanzada del runtime, preparada a partir del primer feedback externo.

## Novedades

- El instalador exige una primera ejecución de BioShock Remastered para confirmar que `Bioshock.ini` ya existe antes de instalar el mod.
- El aviso se muestra de forma visible y el estado se actualiza al volver al instalador.
- El lanzador se cierra cuando Steam o el ejecutable directo aceptan el arranque del juego.
- NVIDIA DLSS 310.7.0.0 continúa incluido como runtime probado y recomendado.
- Se admite una `nvngx_dlss.dll` x64 distinta con advertencia no bloqueante. Con otras versiones no se garantiza funcionamiento, estabilidad ni calidad; el cambio corre por cuenta del usuario.
- Reinstalar restaura la DLL 310.7.0.0 incluida.

## Instalación

1. Abre BioShock Remastered una vez sin el mod, llega al menú principal y ciérralo.
2. Ejecuta el instalador 0.2.2 y selecciona la carpeta `Build\Final` compatible.
3. Instala, elige NORMAL, DLAA o DLSS y pulsa **Guardar e iniciar**.

## Importante

- Esta es una beta experimental y el ejecutable no está firmado digitalmente.
- No incluye DLSS 5 Neural Rendering, Frame Generation ni Ray Reconstruction.
- El host sigue aplicando la asignación probada K/M/L; una DLL distinta puede interpretar o soportar esos perfiles de forma diferente.
- Cierra el juego antes de instalar o restaurar.
