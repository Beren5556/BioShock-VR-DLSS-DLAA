# BioShock 1–2 VR · DLSS/DLAA · 0.2.17 English

One native MSI includes the complete mods for **BioShock Remastered** and
**BioShock 2 Remastered**. Select one game from the first-screen dropdown;
each run manages only that game's mod. To install both, run the same MSI
once per game. You do not need to install the original VR mod first.

## What changed

Installer, launcher, in-headset mod text and documentation are in English.
This is a language edition of the accepted Spanish 0.2.16 release, not an
upstream update or a new rendering implementation. Resolution rules, DLSS
quality choices, defaults, per-game profiles and all four performance
optimizations are retained.

Distribution, core and launcher metadata now identify 0.2.17. The Spanish
0.2.16 release remains available. The verified x64 host and NVIDIA runtime
are reused without rebuilding.

## Installation and use

1. Run the selected game from Steam once, reach its main menu and close it.
2. Close the game and launcher, then open
   **BioShock-1-2-VR-DLSS-DLAA-0.2.17-EN.msi** and select the game.
3. Confirm its `Build\Final` directory, containing `BioshockHD.exe` or
   `Bioshock2HD.exe`. Use **Browse** to select another directory.
4. Complete installation. The launcher is installed beside the game EXE;
   a desktop shortcut is optional. Nothing is launched automatically.
5. Open the launcher, choose NORMAL, DLAA or DLSS, and **Save and launch**.
   The launcher closes only after confirming that the game started. If
   startup cannot be confirmed, it stays open with an explanation.

The launcher EXE keeps its historical `Lanzador BioShock…` filename for
safe MSI upgrades. Installed `LEEME-DLSS45.md`, `RENDIMIENTO.md` and
existing backup-directory names are also preserved; their user documentation
is English. Numeric separators follow the Windows locale.

Profiles remain independent: `%LOCALAPPDATA%\BioshockVR` for BioShock,
and `%LOCALAPPDATA%\BioshockVR\bs2` for BioShock 2. Saves are not modified.
Use the launcher or mod image controls for resolution, not the game's own
settings menu, which can reset the aspect ratio.

## Image controls

- NORMAL: native rendering without DLSS/DLAA.
- DLAA: temporal antialiasing at the selected resolution, 1:1.
- DLSS: reconstruction from a lower internal resolution.
- F1 opens/cycles the in-headset menu; F2 decreases/goes back; F3 increases/goes forward.
- On BioShock 1's Graphics options page, F4 changes the selected setting.
  BioShock 2 graphics effects are saved in the launcher and require a restart.
- The BioShock 2 launcher prepares windowed mode and synchronizes its
  resolution configuration. Its weapon controls are retained.

At 2950 output and 50% DLSS quality, the internal size remains 1476 pixels,
not 1474: it must be even without falling below NVIDIA's minimum. Unsupported
settings keep the previous configuration and show an error.

## Update, repair and uninstall

Open the same MSI and select the game. Updating and repairing preserve
preferences and the first backup of original files. Repair restores bundled
components, including the NVIDIA runtime. Uninstall removes owned mod files
and restores known originals; preferences and recovery backups are retained.

Legacy BioShock 2 beta migration verifies its inventory and backups. If
information needed for safe recovery is missing, it stops and explains why.
Do not delete the previous mod's files or backups before upgrading.

## Compatibility and validation limits

Requires 64-bit Windows, compatible Steam Remastered game builds and a PCVR
headset/runtime supported by BioShock VR v0.8.2. DLSS/DLAA require NVIDIA RTX
hardware and a compatible driver. NVIDIA `nvngx_dlss.dll` **310.7.0.0 x64**
is included; alternative x64 versions are allowed with a warning, without
compatibility guarantees. No DLSS 5 Neural Rendering or Frame Generation.

The user accepted the Spanish base in both games. That acceptance is not
a physical-headset test of these newly compiled English binaries.
Automated checks do not guarantee identical behavior on all computers,
headsets, scenes or resolutions. Second-PC validation is still pending.
See `RENDIMIENTO.md` for performance limits.
