# BioShock VR DLSS/DLAA Beta 0.2 — historical prerelease

First technical prerelease based on BioShock VR v0.8.2; superseded by v0.2.1-beta for public presentation. Retained for traceability; use the repository's current release for new installations.

Historical asset: **Instalador BioShock VR DLSS-DLAA Beta 0.2.exe**. Self-contained VR mod, per-eye bridge, runtime, licenses and launcher.
SHA-256: `08EEE09B4DF57997C84DE441BC3061FCBFD0E9983F5DD1819C20300E80F9D5E8`.

## Changes

- One Build\Final selection; no existing mod required.
- Native Windows UI and previous-state restoration.
- Simplified NORMAL/DLAA/DLSS 4.5 launcher.
- Independent per-eye processing/temporal memory.
- Game version, backend capability and payload hash validation.
- FXAA, spatial upscaling and full Bioshock.ini editor removed from UI.

## Requirements and limits

Compatible Windows BioShock Remastered/BioShock VR v0.8.2, PCVR environment and NVIDIA RTX for DLAA/DLSS. Supported BioshockHD.exe SHA-256:
`AEC21A0072CFDB15E4B525E2320C87256F14F16894F714272069270AD099A05B`.
NORMAL does not use DLSS.

Experimental unsigned executable. No DLSS 5 Neural Rendering, Frame Generation or Ray Reconstruction. Close game before install/restore. Keep installer: restoration uses the first installation's saved state. No game files/assets included.
