# BioShock VR DLSS/DLAA Beta 0.2

Primera prepublicación técnica del fork basado en BioShock VR v0.8.2. Sustituida por v0.2.1-beta para su presentación pública.

> Esta versión se conserva por trazabilidad. Para nuevas instalaciones utiliza [v0.2.1-beta](https://github.com/Beren5556/BioShock-VR-DLSS-DLAA/releases/tag/v0.2.1-beta).

## Descarga

Descarga **Instalador BioShock VR DLSS-DLAA Beta 0.2.exe** desde los activos de esta versión. Es autónomo: incluye el mod VR, el puente DLSS por ojo, el runtime necesario, las licencias y el lanzador.

SHA-256:

    08EEE09B4DF57997C84DE441BC3061FCBFD0E9983F5DD1819C20300E80F9D5E8

## Novedades

- Instalación desde una única selección de la carpeta Build\Final.
- No requiere una copia preexistente de BioShock VR.
- Interfaz nativa de Windows y restauración de la situación anterior.
- Lanzador simplificado con NORMAL, DLAA y DLSS 4.5.
- Procesamiento y memoria temporal independientes por ojo.
- Comprobaciones de versión del juego, capacidades del backend y hashes del contenido.
- FXAA, reescalado espacial y editor completo de Bioshock.ini retirados de la interfaz.

## Requisitos

- BioShock Remastered para Windows en una revisión compatible con BioShock VR v0.8.2.
- El instalador espera BioshockHD.exe con SHA-256 AEC21A0072CFDB15E4B525E2320C87256F14F16894F714272069270AD099A05B.
- Entorno PCVR compatible.
- GPU NVIDIA RTX para DLAA y DLSS.

## Importante

- Esta es una beta experimental y el ejecutable no está firmado digitalmente.
- No incluye DLSS 5 Neural Rendering, Frame Generation ni Ray Reconstruction.
- Cierra el juego antes de instalar o restaurar.
- Conserva el instalador: su opción de restauración utiliza el estado guardado de la primera instalación.
- El proyecto no incluye archivos ni recursos de BioShock Remastered.
