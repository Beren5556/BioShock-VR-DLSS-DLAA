# BioShock VR DLSS/DLAA 0.2.11 — historical public release

Public BS1 Remastered release at that time; the published installer is exactly the tested package, without rebuilding.

## Download and install

Historical asset: **BioShock-VR-DLSS-DLAA-0.2.11.msi**. Self-contained mod package, not game/assets. For current releases see the repository README.

Close game/launcher. Install into the folder containing **BioshockHD.exe**, normally BioShock Remastered\Build\Final; automatic detection is attempted. Existing users should delete nothing: preferences are retained and components upgraded. Reopen same MSI for **Repair**.

Desktop shortcut checkbox defaults on; shortcut **BioShock VR DLSS-DLAA 0.2.11**. Otherwise open **Lanzador BioShock VR DLSS-DLAA.exe** from the chosen folder. Fresh game installations must run once without the mod to create configuration.

## Included improvements

- Windows MSI upgrade/repair, recoverable backups, optional shortcut, no automatic launcher opening.
- Fixed RBF permission errors and other-installed-version warning.
- Compact launcher: square per-eye output, NORMAL/DLAA/DLSS, DLSS quality/calculated internal resolution.
- Four tested performance optimizations. Defaults: reflections/ripples off, other tested effects on, fluids High. Upgrade preserves preferences.
- Recovery from persistent loss of stereo depth after automatic second-eye disable. Bounds/eye separation retained; not all NVIDIA failures claimed fixed.

## Headset controls

**F1** opens/cycles pages; **F2** decrease/previous, **F3** increase/next. Resolution **100-pixel** steps; DLSS quality **5-percentage-point** steps.
Only **Graphics options** uses F2/F3 row selection and **F4** value toggle. Restart if an effect does not apply live.

## NVIDIA and compatibility

Includes tested **NVIDIA DLSS 310.7.0.0**. Manual alternative x64 DLLs allowed at user's risk with warning, not blocked; no compatibility guarantee. Repair reinstalls included DLL. **No DLSS 5 Neural Rendering.**

Requires BioShock Remastered compatible with BioShock VR v0.8.2 and compatible PCVR. DLSS/DLAA require supported NVIDIA RTX.
