# Performance · BioShock 1–2 VR DLSS/DLAA · 0.2.16

Distribution 0.2.16 retains exactly the cores/launchers successfully user-tested in both games, without packaging-time rebuilding.

## Retained optimizations

- Overlapping per-eye DLSS work.
- Depth reuse only when no invalidating writes occurred.
- Frame-tail work overlapped with DLSS.
- Headset delivery before completing the desktop mirror.

Each game retains its own camera/depth capture, projection, weapons and exit behavior. Shared optimizations do not mean identical engine passes/costs.

## Expectations

DLAA processes full resolution and can cost more than NORMAL. DLSS reduces internal resolution but adds processing, copies and synchronization. Results depend on bottleneck/scene; no universal FPS improvement guarantee.

Earlier BS1 tests found major reflection cost and smaller ripple cost. Fresh defaults disable both; upgrades preserve preferences. BS2 graphics changes require launcher save/restart.

Audit found fewer BS2 depth-reuse opportunities than BS1 in different scenes. Not a controlled comparison or proof of a water bug. Validated core retains passive BS2 diagnostic counters; depth guards/eye separation are not weakened to improve those counters artificially.

DLSS range fix prevents mode-change resolution rejection; it is not presented as an FPS optimization. Acceptance on one computer does not replace other-headset/computer testing.
