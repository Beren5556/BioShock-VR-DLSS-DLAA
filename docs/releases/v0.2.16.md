# BioShock 1–2 VR · DLSS/DLAA · Spanish 0.2.16 distribution

One native MSI includes complete mods for **BioShock Remastered** and **BioShock 2 Remastered**. Initial dropdown chooses one game; each run manages only that mod. Owners of both games run the same MSI once per game. No prior original-mod install needed.

This document is translated for the English branch; the original Spanish MSI is unchanged.

## Installation and use

1. Launch the selected game once through Steam, reach the main menu, then close it.
2. With game/launcher closed, open **BioShock-1-2-VR-DLSS-DLAA-0.2.16.msi** and choose the game.
3. Confirm Build\Final containing BioshockHD.exe (BS1) or Bioshock2HD.exe (BS2); Browse changes the path.
4. Finish installation. Desktop shortcut optional; launcher installs in the game folder and is not opened automatically.
5. Open the corresponding launcher, choose NORMAL/DLAA/DLSS and **Save and launch**. Launcher closes only when startup is confirmed; otherwise it stays open and reports the problem.

Independent settings/backups: %LOCALAPPDATA%\BioshockVR for BS1, %LOCALAPPDATA%\BioshockVR\bs2 for BS2. Saves are not included/modified. Change resolution through launcher/mod controls, not the game's internal options.

## Image and controls

- NORMAL: no DLSS. DLAA: antialiasing at selected resolution. DLSS: reconstruction from smaller internal rendering.
- F1 opens/cycles headset pages; F2 decreases/previous, F3 increases/next.
- BS1 F4 changes selected value only in **Graphics options**. BS2 graphics effects save through launcher and require restart.
- BS2 launcher prepares windowed mode and synchronizes resolution files; weapon controls retained.

Internal-resolution rounding fixed: 2950 per-eye output at 50% uses even 1476 pixels, above NVIDIA's minimum. Other unsupported combinations retain the prior setting and explain rejection.

## Upgrade, repair and removal

Open the same MSI and choose the game. Installation over an earlier mod upgrades only that mod. Repair restores packaged files/runtime while preserving preferences and the first-original backup. Uninstall removes owned files/restores known originals. Settings/recovery backups remain.

BS2 beta migration verifies inventories/backups. Missing safe-recovery data stops migration with an explanation. Do not delete old mod files/backups first.

## Compatibility and limits

Requires 64-bit Windows, compatible Steam Remastered games supported by BioShock VR v0.8.2 and a compatible PCVR headset/runtime. DLSS/DLAA require NVIDIA RTX and compatible driver. Includes x64 nvngx_dlss.dll **310.7.0.0**; other x64 versions allowed with warning, without guarantee. No DLSS 5 Neural Rendering or Frame Generation.

User confirmed both mods on their computer. Automation/acceptance does not guarantee identical behavior across computers, headsets, scenes or resolutions. Another-PC testing remains pending; no equal-FPS claim. See RENDIMIENTO.md for optimizations/limits.

Shared distribution/installer version **0.2.16**; core/launcher internals **0.2.13**: exact accepted binaries, not rebuilt merely to change labels.
