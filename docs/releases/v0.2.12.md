# BioShock VR DLSS/DLAA 0.2.12

This stable release adds a Spanish/English language choice while preserving the
rendering, stereo-recovery and performance work validated in 0.2.11.

## What is new

- One Windows Installer package starts with a bilingual language screen. The
  selected language is used by the rest of the installer, the launcher and the
  in-headset F1 menu.
- The language choice is retained when the package is repaired or the mod is
  updated.
- English text has been added for launcher tabs, graphics controls, status and
  validation messages, tooltips, and the live in-game controls.
- The package still creates the versioned desktop shortcut by default and can
  repair an existing installation without a manual uninstall.

## Preserved behaviour

- NORMAL, DLSS and DLAA retain the tested stereo-recovery path.
- All four validated performance optimizations remain enabled.
- Headset resolution changes in 100-pixel steps. DLSS quality changes by five
  percentage points in the in-game menu and by 100 internal pixels in the
  launcher.
- F1 opens the in-headset menu and moves through its pages. F2 selects the
  previous/lower value and F3 selects the next/higher value. F4 changes a value
  only on the Graphics Options page.
- Reflections and water ripples remain disabled in the recommended defaults;
  all other tested graphics settings are enabled and fluid detail is High.

## Installation

Run the game once from Steam before installing, then close the game and the
launcher. Start the 0.2.12 MSI, choose Spanish or English, and confirm the
detected BioShock Remastered `Build\Final` folder. The installer keeps personal
INI settings and can upgrade 0.2.11 directly.

NVIDIA DLSS 310.7.0.0 is included and is the tested runtime. A different x64
DLSS DLL is allowed with a non-blocking warning, but is used at the user's own
risk. Repairing the installation restores the included runtime. This release
does not contain DLSS 5 Neural Rendering.
