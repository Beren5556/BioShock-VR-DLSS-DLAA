# BioShock 1–2 VR DLSS/DLAA 0.2.17 — English edition

The installer, both launchers, in-headset mod menus and documentation are now
in **English**. This is a text-only edition of the accepted Spanish **0.2.16**
release: the rendering behavior, DLSS/DLAA safeguards, per-game settings and
four performance optimizations are preserved.

## Download

**BioShock-1-2-VR-DLSS-DLAA-0.2.17-EN.msi**

One native MSI includes both complete mods. Select **BioShock Remastered** or
**BioShock 2 Remastered** from the first-screen dropdown. Each run manages only
the selected game; run the same MSI again to install the other. No separate
installation of the original VR mod is needed.

Start the chosen game once from Steam, close it, then run the MSI. Confirm its
`Build\Final` folder. The launcher is installed beside the game executable;
a desktop shortcut is optional. Installation does not launch anything automatically.

Existing Spanish 0.2.16 installations can be upgraded per game. Preferences
and recovery backups are preserved. Historical launcher/document filenames
remain unchanged to preserve upgrade identities; the interfaces and user
documentation are English. Numeric separators still follow Windows settings.

## Checks performed

- Exact source comparison against Spanish 0.2.16: 241 files, 1,364 mapped
  translation occurrences; no rendering/control-flow changes.
- Release build, 12 core test executables and self-tests for both launchers.
- Real NVIDIA runtime transition tests: 16 checks per game profile.
- Both launchers' seven tabs and the in-headset layout reviewed.
- 46 MSI payload files verified; English dialogs and component identities checked.
- 130 isolated installer checks across 22 operations, including Spanish-to-English
  upgrades, repair, rollback, uninstall and preservation of the other game.

The English rebuild has **not** had a new physical-headset or second-PC test.
The game installations used for the accepted Spanish release were not modified.
See the [validation report](https://github.com/Beren5556/BioShock-VR-DLSS-DLAA/blob/codex/english-v0.2.17/docs/ENGLISH-0.2.17.md).

DLSS/DLAA require NVIDIA RTX hardware. The unchanged x64 host and NVIDIA
runtime **310.7.0.0** are included. No Frame Generation or DLSS 5 Neural
Rendering. Use the launcher/mod controls for resolution; the game's own
settings can reset the aspect ratio.

The [Spanish 0.2.16 release](https://github.com/Beren5556/BioShock-VR-DLSS-DLAA/releases/tag/v0.2.16)
and Spanish source branch remain available.
