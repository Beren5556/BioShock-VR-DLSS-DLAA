MODES AND HISTORICAL CONTROLS
NORMAL: no DLSS/DLAA. DLAA: native temporal antialiasing. DLSS 4.5 SR: reconstruct smaller internal rendering.
FXAA/old spatial-upscaler UI removed; both disabled on save/start.
F1 DLSS: Mode / Resolution / DLSS Quality / DLSS Sharpness / hide.
F1 NORMAL/DLAA: Mode / Resolution / hide.
In this historical candidate F2 increases and F3 decreases; hidden controls do nothing. Mode cycles NORMAL/DLSS/DLAA; F6 no longer changes it. Later releases reverse F2/F3 to previous/decrease and next/increase.
Resolution/quality steps unchanged from 0.2.5.
Post-DLSS sharpness 0–100%, step 5, default 0 preserving original image; DLSS only, preference retained.
Smaller text/lower headset panel. NORMAL/DLAA remain 100%, retaining DLSS preference.
Live resolution changes use windowed mode; startup forcing was then pending.
Water investigation added sampled copy/wait counters, not a claimed FPS optimization.

INSTALLATION AND RESTORATION
First run original BioShock Remastered through Steam to main menu and close it to create Bioshock.ini. Installer checks the INI, asks only for compatible Build\Final and verifies BioshockHD.exe.
Installation does not change INIs; replaced files are backed up.
Restore recovers prior files/removes empty owned directories, retaining preferences/recovery backup.
Desktop launcher shortcut created. Failed automatic opening does not invalidate installation; manual path shown.
Launcher waits up to 30 seconds for Steam's BioshockHD.exe, closing only after detecting it or successful direct start. Failure keeps launcher open with explanation.

NVIDIA AND LICENSES
