# Agradecimientos

## Mohamad Balouza · creador de BioShock VR

Este fork solo es posible gracias al extraordinario trabajo de **[Mohamad Balouza](https://github.com/mohamad-balouza)**, creador de [BioShock VR](https://github.com/VR-Stereo-Hub/bioshock-trilogy-vr).

Mohamad resolvió la parte fundamental y más difícil del proyecto: integrar BioShock con realidad virtual, producir renderizado estereoscópico, seguimiento de cabeza 6DOF, controladores de movimiento, manos, apuntado, HUD y compatibilidad con distintos runtimes VR. Este repositorio construye sobre esa enorme base para experimentar con DLSS/DLAA y facilitar su instalación. No pretende sustituir el proyecto original ni atribuirse su trabajo.

Nuestro agradecimiento más sincero es para Mohamad y para las personas que colaboran en **VR-Stereo-Hub**. Recomendamos visitar, seguir y apoyar el proyecto original:

- [Repositorio original de BioShock VR](https://github.com/VR-Stereo-Hub/bioshock-trilogy-vr)
- [Versión base exacta v0.8.2](https://github.com/VR-Stereo-Hub/bioshock-trilogy-vr/releases/tag/v0.8.2)
- [Perfil de Mohamad Balouza](https://github.com/mohamad-balouza)
