BIOSHOCK 1-2 VR · DLSS/DLAA 0.2.13 — HISTORICAL LOCAL CANDIDATE
Selected package: BioShock 2 Remastered (Steam 409720).

Includes the BioShock 2 VR adapter, DLSS/DLAA core, compact launcher and NVIDIA DLSS 310.7.0.0. Does not include the game or replace its EXE.
BioShock VR v0.8.2 was created by Mohamad Balouza / VR-Stereo-Hub.
This Beren5556 fork retains their credits and licenses.

Before installation, run the game once through Steam and close it.
Choose Build\Final containing the compatible Bioshock2HD.exe.
The launcher is installed there. The desktop receives only a shortcut, if selected. Installation does not automatically start the game.

The launcher treats Shared.ini as the resolution authority and synchronizes Bioshock2SP.ini. Save prepares windowed mode. It closes only after confirming the correct new process and a responsive window.
F1 cycles image pages; F2 previous/decrease; F3 next/increase.
BS2 graphics options are changed in the launcher: save and restart.
Live F4 changes are not implemented for BS2.

Upgrade/repair preserves preferences. Repair reinstalls included binaries, including NVIDIA 310.7.0.0. Alternative x64 versions are allowed with a warning and no guarantee.
Uninstall removes mod files and restores known originals.
Migration from beta 0.1.0/0.1.1 verifies all 21 backups; beta DLLs are not treated as original game files. A missing backup rejects migration.
Backups and personal INIs remain; saves are untouched.

Separate profile: %LOCALAPPDATA%\BioshockVR\bs2.
MSI backups: %LOCALAPPDATA%\BioshockVR\bs2\WindowsInstaller.
At this historical stage BS1 remained separate with its accepted 0.2.11 MSI.

Pending at that stage: headset testing (performance, water, modes, resolution, stereo, loading and exit), coexistence and another computer.
No DLSS 5 or Frame Generation. This historical candidate was not a stable release.
